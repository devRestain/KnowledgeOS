# KnowledgeOS Record Schemas

## Definition and contents

- Use this directory for domain, provider, proposal, evidence, and MCP record shapes.
- Use mcp for the declared local protocol schemas.

## Ownership

- Keep these domain schemas distinct from Core common record schemas.
- Preserve declared generated-schema ownership.

## Use and maintenance

- Use the existing schema generator and canonical schema check for derived files.
- Avoid inserting experimental wire records without a selected domain implementation need.
