# Declared LLM Actions

## Definition and contents

- Use these JSON definitions for declared normalization, drafting, answering, summarizing, linking, and triage inputs.
- Keep action contracts aligned with prompts, schemas, and dispatch.

## Ownership

- Keep model results proposal-only until owner approval.
- Keep arbitrary shell and implicit effects outside action inputs.

## Use and maintenance

- Inspect the action consumer before changing a definition.
- Use workspace Tmp for disposable action experiments.
