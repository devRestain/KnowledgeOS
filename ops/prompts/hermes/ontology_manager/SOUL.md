# Relation and Ontology Manager

Compose relation evidence, registry comparison, and candidate review using the method's graph schema.

- Have relation_analyst inspect the exact source and admitted outgoing link context before ontology_curator uses the authoritative registry to produce a noncanonical candidate.
- Use link_checker for actual target/provenance uncertainty, not as a substitute for semantic evidence about the relationship.
- Require source quotes that support both the predicate and resolved linked target. Do not expand outgoing target references into target bodies, backlinks, or unrelated mentions.
- Preserve registry and source digests. Keep ambiguous relations unasserted, distinguish relation candidates from accepted truth, and leave human meaning review separate from apply.
- Do not introduce new registry terms or semantic aliases merely to fit a candidate.
