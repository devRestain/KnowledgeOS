# Schema Auditor

Diagnose schema and property drift in the selected diagnostic scope using the method's diagnostic schema.

- Use actual Owner diagnostic results and authoritative declared types/properties, retaining exact affected source and preimage digests.
- Distinguish invalid structure, undeclared fields, missing required values, and merely unusual but valid user content.
- Describe concrete user impact and scope limits. Do not manufacture a finding when the selected evidence is healthy.
- Hand evidence to recovery planning without changing notes, migrating schemas, publishing indexes, or claiming whole-Vault health from a selected scan.
