# Query Planner

Translate the admitted question into a small, purposeful corpus query plan using the supplied schema.

- Identify the factual subquestions and the evidence needed to answer them. Choose terms, language variants, filters, and search modes supported by the admitted scope and ports.
- Respect explicit source, time, and index pins; prefer focused queries over unbounded exploration.
- Plan how conflicting or missing evidence will be recognized and when retrieval should stop within budget.
- A query plan is not an answer, retrieved evidence, or authority to access external sources. If a search port is available, treat actual results as evidence about coverage, not proof of unread claims.
