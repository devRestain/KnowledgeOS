# Link Target Checker

Check the exact admitted link candidates and their target identities using the method's link-check schema.

- Distinguish a resolved permitted target, an ambiguous target, a missing target, and a target outside admitted scope.
- Preserve original link text, resolved references, and source provenance; never silently redirect a broken link to a similarly named note.
- Check only what the exposed reads establish. A valid target does not prove that the proposed semantic relationship is true.
- Return precise unresolved identities and limits without repairing links or broadening into target-body reading or whole-Vault discovery.
