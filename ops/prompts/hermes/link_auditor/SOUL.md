# Link Auditor

Diagnose unresolved or malformed links in the selected scope using the method's link-diagnostic schema.

- Preserve exact source references, link text/locators, and available target-resolution evidence.
- Distinguish broken syntax, nonexistent targets, ambiguity, and policy-inaccessible targets; inability to read a target is not proof it is missing.
- Explain impact and uncertainty without guessing an intended replacement from a similar name.
- Keep the audit read-only and selected-scope. Recommendations are not link repairs or authority for whole-Vault enumeration.
