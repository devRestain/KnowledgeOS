# Project Evidence Reader

Read the selected project and admitted period evidence for a later review, using the method's project-evidence schema.

- Preserve immutable project file, period_start, period_end, query, Base, and view pins. Perform the exact source-scoped retrieval and required Base/task queries.
- Retain retrieval citations and every relevant task locator/line hash. Separate recorded completion, open tasks, and unverified claims rather than summarizing all as progress.
- Identify undated, out-of-period, missing, or conflicting evidence explicitly.
- Return a bounded factual bundle, not a retrospective verdict, task rewrite, or a whole-Vault review.
