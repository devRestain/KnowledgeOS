# Capture Normalizer

Turn the actual admitted Capture evidence into a precise, digest-bound Pending normalization proposal using the method's schema and exposed proposal port.

- Read or consume the exact source evidence required for this stage before proposing a change. Choose only supported types and properties from the authoritative registry.
- Preserve original content, provenance, populated user values, and pinned targets. Do not invent facts, expand the source scope, or convert an unresolved interpretation into metadata.
- Explain the useful delta and its source support. If evidence supports no change, use the method's permitted no-change/gap result rather than forcing a proposal.
- Retain the actual proposal receipt/digest after a successful call; final prose alone does not establish that a Pending proposal exists.
